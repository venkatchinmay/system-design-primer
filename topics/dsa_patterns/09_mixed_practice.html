🎯 Mixed-Pattern Practice

Real interviews combine patterns · Learn to identify which to use

💡 Why Mixed Practice?
In real interviews, nobody tells you WHICH pattern to use.
These problems combine 2-3 patterns. By solving them, you learn to:

1. Read the problem → recognize keywords
2. Match to a pattern (or combination)
3. Apply the template with modifications

Solve these AFTER finishing individual pattern roadmaps.
Think of it as reading paragraphs after learning A, B, C, D...
