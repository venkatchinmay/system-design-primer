Binary Search
🌍 Real-World Analogy
Looking up a word in a dictionary — you open to the middle, check if your word is before or after, then repeat on the correct half. Each step eliminates HALF the remaining pages. 1000 pages? Only 10 steps! That's O(log n).
🧠 When To Recognize
sorted arrayfind target/boundaryO(log n) requiredsearch in rotatedfind min/max that satisfiesbinary search on answer
📐 Step-by-Step Visual

Problem: Find target = 7 in [1, 3, 5, 7, 9, 11]

Step-by-step elimination
  [1, 3, 5, 7, 9, 11]    lo=0, hi=5, mid=2 → nums[2]=5 < 7 → lo=3
  [         7, 9, 11]    lo=3, hi=5, mid=4 → nums[4]=9 > 7 → hi=3
  [         7        ]    lo=3, hi=3, mid=3 → nums[3]=7 = 7  ✅ Found!
  
  3 steps instead of 6! O(log n) vs O(n)
  
  Key variants:
  • Find exact target:   lo <= hi, return mid
  • Find leftmost:       lo < hi, if match hi=mid
  • Find rightmost:      lo < hi, if match lo=mid+1
  • Search on answer:    binary search on the RESULT space
💻 Code
// Standard Binary Search — O(log n)
int binarySearch(int[] nums, int target) {
    int lo = 0, hi = nums.length - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;   // avoid overflow!
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

// Find first occurrence (leftmost)
int lowerBound(int[] nums, int target) {
    int lo = 0, hi = nums.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] < target) lo = mid + 1;
        else hi = mid;            // don't skip — might be the answer
    }
    return lo;
}

func binarySearch(nums []int, target int) int {
    lo, hi := 0, len(nums)-1
    for lo <= hi {
        mid := lo + (hi-lo)/2
        if nums[mid] == target { return mid }
        if nums[mid] < target { lo = mid+1 } else { hi = mid-1 }
    }
    return -1
}

def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target: return mid
        elif nums[mid] < target: lo = mid + 1
        else: hi = mid - 1
    return -1

⚠️ Edge Cases & Common Mistakes
  • Use lo + (hi - lo) / 2 instead of (lo + hi) / 2 to avoid integer overflow.
  • Off-by-one errors: carefully choose lo <= hi vs lo < hi and hi = mid vs hi = mid - 1.
  • Binary search on answer: when the problem says "find the minimum/maximum value that satisfies condition" — binary search on the answer space!
  • Rotated array: check which half is sorted, then decide which half to search.

O(log n)

Just two pointers (iterative).

Merge Intervals
🌍 Real-World Analogy
Scheduling meetings — if one meeting is 9-11 and another is 10-12, they overlap and become one block 9-12. Sort all meetings by start time, then scan through: if the current meeting overlaps with the previous, merge them. Otherwise, it's a new separate block.
🧠 When To Recognize
intervalsoverlapping meetingsmerge/insert intervalmeeting roomsminimum platformsnon-overlapping
📐 Step-by-Step Visual
Merge [[1,3],[2,6],[8,10],[15,18]]
  Sorted by start: [1,3], [2,6], [8,10], [15,18]
  
  Take [1,3]. Next [2,6]: 2 ≤ 3 → overlap! → merge to [1,6]
  Next [8,10]: 8 > 6 → no overlap → add new [8,10]
  Next [15,18]: 15 > 10 → no overlap → add [15,18]
  
  ✅ Result: [[1,6],[8,10],[15,18]]
💻 Code
// Merge Intervals (LC #56) — Time: O(n log n)  Space: O(n)
public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a,b) -> a[0]-b[0]);
    List<int[]> res = new ArrayList<>();
    res.add(intervals[0]);
    for (int i = 1; i < intervals.length; i++) {
        int[] last = res.get(res.size()-1);
        if (intervals[i][0] <= last[1])       // overlap
            last[1] = Math.max(last[1], intervals[i][1]);
        else
            res.add(intervals[i]);              // no overlap
    }
    return res.toArray(new int[0][]);
}

func merge(intervals [][]int) [][]int {
    sort.Slice(intervals, func(i,j int) bool { return intervals[i][0] < intervals[j][0] })
    res := [][]int{intervals[0]}
    for _, iv := range intervals[1:] {
        last := res[len(res)-1]
        if iv[0] <= last[1] {
            last[1] = max(last[1], iv[1])
        } else {
            res = append(res, iv)
        }
    }
    return res
}

def merge(intervals):
    intervals.sort(key=lambda x: x[0])
    res = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= res[-1][1]:
            res[-1][1] = max(res[-1][1], end)
        else:
            res.append([start, end])
    return res
⚠️ Edge Cases
  • Single interval → return as-is. All overlapping → one big interval.
  • Meeting Rooms II: use sweep line (sort starts/ends separately, or min-heap of end times).
  • When inserting a new interval, it may merge with multiple existing intervals.

Cyclic Sort
🌍 Real-World Analogy
Numbered lockers — each item has a number and should go in the matching locker. Pick up item, put it in its correct locker, take whatever was there, repeat. After one pass, anything in the wrong spot reveals a missing or duplicate number.
🧠 When To Recognize
numbers 1 to Nmissing numberfind duplicatefirst missing positivein-place, O(1) space
📐 Step-by-Step Visual
Find Missing Number in [3, 0, 1] (range 0-3)
  Place each number at index = its value:
  i=0: nums[0]=3, should be at index 3 (out of bounds) → skip, i++
  i=1: nums[1]=0, should be at index 0 → swap → [0, 3, 1]
  i=1: nums[1]=3, out of bounds → skip
  i=2: nums[2]=1, should be at index 1 → swap → [0, 1, 3]
  
  Now scan: nums[i] ≠ i?  →  index 2 has 3, not 2  → ✅ missing = 2
💻 Code
// Missing Number (LC #268) — O(n) time, O(1) space
public int missingNumber(int[] nums) {
    int i = 0;
    while (i < nums.length) {
        if (nums[i] < nums.length && nums[i] != i)
            swap(nums, i, nums[i]);    // place at correct index
        else i++;
    }
    for (i = 0; i < nums.length; i++)
        if (nums[i] != i) return i;
    return nums.length;
}

// First Missing Positive (LC #41) — same idea, range [1..n]
public int firstMissingPositive(int[] nums) {
    int n = nums.length;
    for (int i = 0; i < n; i++)
        while (nums[i] > 0 && nums[i] <= n && nums[nums[i]-1] != nums[i])
            swap(nums, i, nums[i]-1);
    for (int i = 0; i < n; i++)
        if (nums[i] != i+1) return i+1;
    return n+1;
}

func missingNumber(nums []int) int {
    for i := 0; i < len(nums); {
        if nums[i] < len(nums) && nums[i] != i {
            nums[i], nums[nums[i]] = nums[nums[i]], nums[i]
        } else { i++ }
    }
    for i, n := range nums { if n != i { return i } }
    return len(nums)
}

def missing_number(nums):
    i, n = 0, len(nums)
    while i < n:
        if nums[i] < n and nums[i] != i:
            nums[nums[i]], nums[i] = nums[i], nums[nums[i]]
        else:
            i += 1
    for i in range(n):
        if nums[i] != i: return i
    return n
