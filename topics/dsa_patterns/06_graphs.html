BFS on Graph
🌍 Real-World Analogy
A ripple from a stone dropped in a pond — the wave reaches nearby points first, then farther points. BFS explores all nodes at distance 1, then distance 2, then 3... This guarantees the shortest path in unweighted graphs.
🧠 When To Recognize
shortest path (unweighted)nearest/closestlevel-by-levelminimum stepsspread/infectionmulti-source BFS
📐 Step-by-Step Visual

Problem: Rotting Oranges — how many minutes until all oranges rot?
Grid: 2=rotten, 1=fresh, 0=empty

Step 1 — Find all starting points (multi-source)
  Grid:   [2, 1, 1]      Queue: [(0,0)]    fresh = 4
          [1, 1, 0]      All rotten oranges go into queue first
          [0, 1, 1]
Step 2 — Process level by level (each level = 1 minute)
  Minute 1: (0,0) rots → (0,1) and (1,0)    fresh = 2
  Minute 2: (0,1)→(0,2), (1,0)→(1,1)        fresh = 0... wait
  Minute 3: (0,2)→nothing, (1,1)→(2,1)       
  Minute 4: (2,1)→(2,2)                      fresh = 0 → ✅ Answer: 4
💡 Key insight
  BFS level = time step. By processing ALL nodes at same distance
  together (for i in range(len(queue))), we track "waves".
  Multi-source = multiple starting points in queue at once.
💻 Code
// Rotten Oranges (LC #994) — Multi-source BFS
// Time: O(m×n)  Space: O(m×n)
public int orangesRotting(int[][] grid) {
    int m = grid.length, n = grid[0].length, fresh = 0;
    Queue<int[]> q = new LinkedList<>();
    for (int r = 0; r < m; r++)           // Step 1: find all rotten
        for (int c = 0; c < n; c++) {
            if (grid[r][c] == 2) q.offer(new int[]{r, c});
            if (grid[r][c] == 1) fresh++;
        }
    if (fresh == 0) return 0;              // nothing to rot
    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    int mins = 0;
    while (!q.isEmpty() && fresh > 0) {
        mins++;                             // one minute per level
        for (int i = q.size(); i > 0; i--) { // process entire level
            int[] c = q.poll();
            for (int[] d : dirs) {
                int nr = c[0]+d[0], nc = c[1]+d[1];
                if (nr>=0 && nr<m && nc>=0 && nc<n && grid[nr][nc]==1) {
                    grid[nr][nc] = 2; fresh--;
                    q.offer(new int[]{nr, nc});
                }
            }
        }
    }
    return fresh == 0 ? mins : -1;          // -1 if unreachable
}

// Rotten Oranges — Multi-source BFS
func orangesRotting(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    q := [][2]int{}; fresh := 0
    for r := 0; r < m; r++ {
        for c := 0; c < n; c++ {
            if grid[r][c] == 2 { q = append(q, [2]int{r, c}) }
            if grid[r][c] == 1 { fresh++ }
        }
    }
    if fresh == 0 { return 0 }
    dirs := [4][2]int{{0,1},{0,-1},{1,0},{-1,0}}
    mins := 0
    for len(q) > 0 && fresh > 0 {
        mins++
        for i := len(q); i > 0; i-- {
            c := q[0]; q = q[1:]
            for _, d := range dirs {
                nr, nc := c[0]+d[0], c[1]+d[1]
                if nr>=0 && nr<m && nc>=0 && nc<n && grid[nr][nc]==1 {
                    grid[nr][nc] = 2; fresh--
                    q = append(q, [2]int{nr, nc})
                }
            }
        }
    }
    if fresh == 0 { return mins }; return -1
}

from collections import deque
def oranges_rotting(grid):
    m, n = len(grid), len(grid[0])
    q, fresh = deque(), 0
    for r in range(m):
        for c in range(n):
            if grid[r][c] == 2: q.append((r, c))
            if grid[r][c] == 1: fresh += 1
    if fresh == 0: return 0
    dirs, mins = [(0,1),(0,-1),(1,0),(-1,0)], 0
    while q and fresh > 0:
        mins += 1
        for _ in range(len(q)):      # process entire level
            r, c = q.popleft()
            for dr, dc in dirs:
                nr, nc = r+dr, c+dc
                if 0<=nr<m and 0<=nc<n and grid[nr][nc]==1:
                    grid[nr][nc] = 2; fresh -= 1
                    q.append((nr, nc))
    return mins if fresh == 0 else -1

⚠️ Edge Cases & Common Mistakes
  • Forgetting to mark nodes as visited BEFORE adding to queue (causes duplicates and TLE).
  • Multi-source BFS: add ALL starting points to queue before starting — don't run separate BFS for each.
  • Off-by-one in level counting: level increments AFTER processing all nodes at current distance.
  • Grid BFS: check bounds 0 <= nr < m before accessing grid[nr][nc].
⏱️ Complexity
Time
O(V + E)
Visit each node once, check each edge once. For grids: O(m×n).
Space
O(V)
Queue + visited set. Worst case all nodes in queue at once.

DFS on Graph
🌍 Real-World Analogy
Exploring a maze — always go as deep as possible down one path, painting walls as you go. Hit a dead end? Backtrack and try the next unexplored tunnel. DFS is great for counting components, detecting cycles, and exhaustive search.
🧠 When To Recognize
number of islands/componentsconnected componentflood fillcycle detectionpath existssurrounded regionsclone graph
📐 Step-by-Step Visual

Problem: Number of Islands — count connected '1' groups

Step 1 — Scan grid, find unvisited '1'
  Grid:   [1, 1, 0, 0, 0]    Found '1' at (0,0) → count = 1
          [1, 1, 0, 0, 0]    Start DFS from here
          [0, 0, 1, 0, 0]
          [0, 0, 0, 1, 1]
Step 2 — DFS marks entire island as visited
  Grid:   [✓, ✓, 0, 0, 0]    DFS visits (0,1), (1,0), (1,1)
          [✓, ✓, 0, 0, 0]    One DFS call = one complete island
          [0, 0, 1, 0, 0]
          [0, 0, 0, 1, 1]
Step 3 — Continue scanning
  (2,2) → count = 2    (3,3) → count = 3 (also visits 3,4)
  ✅ Answer: 3 islands
💻 Code
// Number of Islands (LC #200) — Time: O(m×n)  Space: O(m×n) stack
public int numIslands(char[][] grid) {
    int count = 0;
    for (int r = 0; r < grid.length; r++)
        for (int c = 0; c < grid[0].length; c++)
            if (grid[r][c] == '1') { count++; dfs(grid, r, c); }
    return count;
}
void dfs(char[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length
        || grid[r][c] != '1') return;
    grid[r][c] = '0';                     // mark visited
    dfs(grid, r+1, c); dfs(grid, r-1, c);
    dfs(grid, r, c+1); dfs(grid, r, c-1);
}

⚠️ Edge Cases & Common Mistakes
  • Modifying input grid to mark visited is OK in interviews (ask interviewer first). Alternative: use a visited[][] boolean array.
  • Stack overflow on very large grids — convert to iterative DFS with explicit stack if grid can be 1000×1000+.
  • DFS vs BFS: for "count components" or "does path exist" → DFS. For "shortest path" → BFS always.
  • Don't forget all 4 directions. For diagonal: use 8 directions.

Topological Sort
🌍 Real-World Analogy
College courses with prerequisites — you MUST take Calc I before Calc II, and Linear Algebra before ML. Topological Sort gives a valid ordering that respects ALL prerequisites. If the prerequisites form a cycle (Calc I requires Calc II requires Calc I), it's impossible!
🧠 When To Recognize
prerequisitesdependenciesorderingcourse schedulebuild orderdirected acyclic graph (DAG)alien dictionary
📐 Step-by-Step Visual — Kahn's Algorithm (BFS-based)

Problem: Course Schedule II — find a valid order to take courses

Step 1 — Build graph + count in-degrees
  Courses: 0→1, 0→2, 1→3, 2→3
  Graph:  0 → [1, 2]     In-degree: 0→0, 1→1, 2→1, 3→2
          1 → [3]         Nodes with in-degree 0 go in queue
          2 → [3]         Queue: [0]
Step 2 — Process queue: remove node, reduce in-degrees
  Pop 0 → output [0], reduce in-deg of 1→0, 2→0
  Queue: [1, 2]   (both became 0)
  Pop 1 → output [0,1], reduce 3→1
  Pop 2 → output [0,1,2], reduce 3→0
  Queue: [3]
  Pop 3 → output [0,1,2,3]   ✅ Valid order!
💡 Cycle detection
  If output.length < numCourses → cycle exists!
  Some nodes never reach in-degree 0 = stuck in a cycle.
💻 Code
// Course Schedule II (LC #210) — Kahn's BFS Topological Sort
// Time: O(V + E)  Space: O(V + E)
public int[] findOrder(int n, int[][] prereqs) {
    List<List<Integer>> g = new ArrayList<>();
    int[] inDeg = new int[n];
    for (int i = 0; i < n; i++) g.add(new ArrayList<>());
    for (int[] p : prereqs) {
        g.get(p[1]).add(p[0]);   // p[1] → p[0]
        inDeg[p[0]]++;
    }
    Queue<Integer> q = new LinkedList<>();
    for (int i = 0; i < n; i++)
        if (inDeg[i] == 0) q.offer(i);  // start with no-prereq courses
    int[] order = new int[n]; int idx = 0;
    while (!q.isEmpty()) {
        int node = q.poll();
        order[idx++] = node;
        for (int next : g.get(node))
            if (--inDeg[next] == 0) q.offer(next);
    }
    return idx == n ? order : new int[0];  // empty = cycle!
}

func findOrder(n int, prereqs [][]int) []int {
    g := make([][]int, n); inDeg := make([]int, n)
    for _, p := range prereqs {
        g[p[1]] = append(g[p[1]], p[0]); inDeg[p[0]]++
    }
    q := []int{}
    for i, d := range inDeg { if d == 0 { q = append(q, i) } }
    order := []int{}
    for len(q) > 0 {
        node := q[0]; q = q[1:]
        order = append(order, node)
        for _, next := range g[node] {
            inDeg[next]--
            if inDeg[next] == 0 { q = append(q, next) }
        }
    }
    if len(order) == n { return order }
    return nil
}

from collections import deque
def find_order(n, prereqs):
    graph = [[] for _ in range(n)]
    in_deg = [0] * n
    for course, pre in prereqs:
        graph[pre].append(course)
        in_deg[course] += 1

    q = deque(i for i in range(n) if in_deg[i] == 0)
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nxt in graph[node]:
            in_deg[nxt] -= 1
            if in_deg[nxt] == 0:
                q.append(nxt)
    return order if len(order) == n else []
⚠️ Edge Cases & Common Mistakes
  • Forgetting to handle disconnected components — nodes with no edges still need in-degree 0 processing.
  • Two approaches: Kahn's (BFS) is easier to implement and returns the order. DFS-based uses post-order reversal.
  • Cycle detection: Kahn's → output.size ≠ n. DFS → finding a node in GRAY (currently being processed) state.
  • Graph direction matters: "0 is a prerequisite of 1" means edge 0 → 1, NOT 1 → 0.
⏱️ Complexity
Time
O(V + E)
Process each node and edge exactly once.
Space
O(V + E)
Adjacency list + in-degree array + queue.

Union-Find (Disjoint Set)
🌍 Real-World Analogy
Groups of friends at a party. When Alice shakes hands with Bob, their friend groups merge into one. Later someone asks "Are Alice and Carlos in the same group?" Union-Find answers this in nearly O(1) using path compression and union by rank.
🧠 When To Recognize
connected components (dynamic)grouping/mergingredundant connectionaccounts mergeMST (Kruskal's)"are X and Y connected?"
�� Step-by-Step Visual
Step 1 — Initialize: everyone is their own parent
  parent: [0, 1, 2, 3, 4]    Each node points to itself
  rank:   [0, 0, 0, 0, 0]    All trees have height 0
Step 2 — Union(0, 1) and Union(2, 3)
  parent: [0, 0, 2, 2, 4]    1→0, 3→2
  Two groups: {0,1} and {2,3} and {4}
Step 3 — Union(1, 3): merges the two groups
  find(1)=0, find(3)=2 → union(0,2) → parent[2]=0
  parent: [0, 0, 0, 2, 4]   Now {0,1,2,3} are one group
  
  Path Compression: find(3) → 3→2→0. Now set parent[3]=0 directly!
  Next call to find(3) is O(1).   ✅ Nearly O(1) per operation!
💻 Code
// Union-Find with Path Compression + Union by Rank
// Time: O(α(n)) ≈ O(1) per operation
class UnionFind {
    int[] parent, rank;
    int components;
    
    UnionFind(int n) {
        parent = new int[n]; rank = new int[n];
        components = n;
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    
    int find(int x) {
        if (parent[x] != x)
            parent[x] = find(parent[x]);  // path compression!
        return parent[x];
    }
    
    boolean union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false;      // already same group
        if (rank[px] < rank[py]) parent[px] = py;
        else if (rank[px] > rank[py]) parent[py] = px;
        else { parent[py] = px; rank[px]++; }
        components--;
        return true;                     // merged!
    }
    
    boolean connected(int x, int y) { return find(x) == find(y); }
}

type UF struct {
    parent, rank []int
    components   int
}
func NewUF(n int) *UF {
    p := make([]int, n)
    for i := range p { p[i] = i }
    return &UF{p, make([]int, n), n}
}
func (u *UF) Find(x int) int {
    if u.parent[x] != x { u.parent[x] = u.Find(u.parent[x]) }
    return u.parent[x]
}
func (u *UF) Union(x, y int) bool {
    px, py := u.Find(x), u.Find(y)
    if px == py { return false }
    if u.rank[px] < u.rank[py] { u.parent[px] = py
    } else if u.rank[px] > u.rank[py] { u.parent[py] = px
    } else { u.parent[py] = px; u.rank[px]++ }
    u.components--; return true
}

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.components = n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # path compression
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py: return False
        if self.rank[px] < self.rank[py]: px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]: self.rank[px] += 1
        self.components -= 1
        return True

    def connected(self, x, y):
        return self.find(x) == self.find(y)
⚠️ Edge Cases & Common Mistakes
  • Always use BOTH path compression + union by rank for O(α(n)). Without optimization, it can degrade to O(n).
  • When to use UF vs DFS/BFS: UF is better for dynamic "add edges and query connectivity". DFS/BFS is for static graphs.
  • Common mistake: Forgetting to find() before comparing — you must compare ROOTS, not direct parents.
  • For problems with strings as nodes (like accounts merge), map strings to integers first.
⏱️ Complexity
Time
O(α(n))
Per operation. α = inverse Ackermann ≈ constant for all practical n.
Space
O(n)
Parent and rank arrays.

Dijkstra / Weighted Shortest Path
🌍 Real-World Analogy
Google Maps finding the fastest route. Start at your location with distance 0. Check all neighboring cities — update their distances if you found a shorter route through the current city. Always process the closest unvisited city next (greedy!). Uses a priority queue (min-heap) to pick the closest city efficiently.
🧠 When To Recognize
shortest path (weighted)minimum costnetwork delaycheapest flightnon-negative weightspriority queue + graph
📐 Step-by-Step Visual

Problem: Find shortest path from node A to all other nodes

Step 1 — Initialize distances
  Graph: A→B(1), A→C(4), B→C(2), B→D(5), C→D(1)
  dist:  A=0, B=∞, C=∞, D=∞
  Heap:  [(0, A)]
Step 2 — Process closest node (A), update neighbors
  Pop (0,A): B = min(∞, 0+1) = 1,  C = min(∞, 0+4) = 4
  Heap: [(1,B), (4,C)]
Step 3 — Process B, update neighbors
  Pop (1,B): C = min(4, 1+2) = 3,  D = min(∞, 1+5) = 6
  Heap: [(3,C), (4,C_old), (6,D)]
Step 4 — Process C (dist=3), update D
  Pop (3,C): D = min(6, 3+1) = 4
  Pop (4,C_old): skip! (4 > 3, already processed)
  Pop (4,D): done!
  
  ✅ Shortest: A→A=0, A→B=1, A→C=3, A→D=4
💻 Code
// Network Delay Time (LC #743) — Classic Dijkstra
// Time: O((V+E) log V)  Space: O(V + E)
public int networkDelayTime(int[][] times, int n, int k) {
    Map<Integer,List<int[]>> g = new HashMap<>();
    for (int[] t : times)
        g.computeIfAbsent(t[0], x->new ArrayList<>()).add(new int[]{t[1],t[2]});
    
    int[] dist = new int[n+1];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[k] = 0;
    
    // Min-heap: [distance, node]
    PriorityQueue<int[]> pq = new PriorityQueue<>((a,b)->a[0]-b[0]);
    pq.offer(new int[]{0, k});
    
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        if (d > dist[u]) continue;      // skip outdated entry
        for (int[] e : g.getOrDefault(u, List.of())) {
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{dist[v], v});
            }
        }
    }
    int mx = 0;
    for (int i = 1; i <= n; i++) mx = Math.max(mx, dist[i]);
    return mx == Integer.MAX_VALUE ? -1 : mx;
}

// Dijkstra using container/heap
import "container/heap"

type Item struct{ node, dist int }
type MinHeap []Item
func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i].dist < h[j].dist }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x any)        { *h = append(*h, x.(Item)) }
func (h *MinHeap) Pop() any          { old := *h; x := old[len(old)-1]; *h = old[:len(old)-1]; return x }

func networkDelayTime(times [][]int, n, k int) int {
    g := make(map[int][][2]int)
    for _, t := range times { g[t[0]] = append(g[t[0]], [2]int{t[1], t[2]}) }
    dist := make([]int, n+1)
    for i := range dist { dist[i] = 1<<31 }; dist[k] = 0
    h := &MinHeap{{k, 0}}
    for h.Len() > 0 {
        cur := heap.Pop(h).(Item)
        if cur.dist > dist[cur.node] { continue }
        for _, e := range g[cur.node] {
            if dist[cur.node]+e[1] < dist[e[0]] {
                dist[e[0]] = dist[cur.node]+e[1]
                heap.Push(h, Item{e[0], dist[e[0]]})
            }
        }
    }
    mx := 0
    for i := 1; i <= n; i++ { if dist[i] > mx { mx = dist[i] } }
    if mx == 1<<31 { return -1 }; return mx
}

import heapq
from collections import defaultdict

def network_delay_time(times, n, k):
    graph = defaultdict(list)
    for u, v, w in times:
        graph[u].append((v, w))

    dist = {i: float('inf') for i in range(1, n+1)}
    dist[k] = 0
    heap = [(0, k)]           # (distance, node)

    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:       # skip outdated
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(heap, (dist[v], v))

    mx = max(dist.values())
    return -1 if mx == float('inf') else mx
⚠️ Edge Cases & Common Mistakes
  • Dijkstra only works with non-negative weights! For negative weights, use Bellman-Ford.
  • The "skip outdated" check if d > dist[u]: continue is crucial for performance — without it, you process stale entries.
  • Don't confuse with BFS: BFS = unweighted shortest path, Dijkstra = weighted shortest path.
  • For problems with constraints like "at most K stops", you may need modified BFS instead of pure Dijkstra.
  • Common in grids too! "Path with minimum effort" treats grid cells as weighted graph.

O((V+E) log V)
Each edge relaxation = heap push O(log V). Total E pushes.

O(V + E)
Distance array + adjacency list + heap.
