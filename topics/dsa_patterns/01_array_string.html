Two Pointers
🌍 Real-World Analogy
Two people walking toward each other from opposite ends of a bridge. One starts at the left, one at the right. They move based on conditions — the tall person moves, or the short one moves. They meet in the middle. This avoids checking every pair!
🧠 When To Recognize
sorted arraypair with target sumremove duplicatescontainer with most waterpalindrome checkmerge sortedthree sum
📐 Step-by-Step Visual

Problem: Two Sum II — sorted array [2, 7, 11, 15], target = 9

Step 1 — Place pointers at both ends
  [2, 7, 11, 15]     left = 0, right = 3
   ↑           ↑      sum = 2 + 15 = 17 > 9 → right--
Step 2 — Too big → move right pointer left
  [2, 7, 11, 15]     left = 0, right = 2
   ↑       ↑          sum = 2 + 11 = 13 > 9 → right--
Step 3 — Found it!
  [2, 7, 11, 15]     left = 0, right = 1
   ↑   ↑              sum = 2 + 7 = 9  ✅ Found!
💡 Why it works
  sum too big → right pointer has the bigger number → move it left
  sum too small → left pointer has the smaller number → move it right
  O(n) instead of O(n²) brute force!
💻 Code
// Two Sum II (LC #167) — Time: O(n)  Space: O(1)
public int[] twoSum(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int sum = nums[left] + nums[right];
        if (sum == target) return new int[]{left+1, right+1};
        else if (sum < target) left++;    // need bigger sum
        else right--;                      // need smaller sum
    }
    return new int[]{};
}

func twoSum(nums []int, target int) []int {
    left, right := 0, len(nums)-1
    for left < right {
        sum := nums[left] + nums[right]
        if sum == target { return []int{left+1, right+1} }
        if sum < target { left++ } else { right-- }
    }
    return nil
}

def two_sum(nums, target):
    left, right = 0, len(nums) - 1
    while left < right:
        s = nums[left] + nums[right]
        if s == target: return [left+1, right+1]
        elif s < target: left += 1
        else: right -= 1
    return []
⚠️ Edge Cases & Common Mistakes
  • Array MUST be sorted for two-pointer to work (or sort it first, but that changes indices).
  • Use left < right (strict), not left <= right — otherwise you compare an element with itself.
  • For 3Sum: fix one number, then two-pointer on the rest. Skip duplicates to avoid duplicate triplets.
  • For remove duplicates in-place: use slow/fast pointer variant (two pointers same direction).
⏱️ Complexity
Time
O(n)
Each pointer moves at most n steps total.
Space
O(1)
Just two pointer variables.

Sliding Window
🌍 Real-World Analogy
Looking through a window on a train — the window frame stays the same size, but the scenery changes as you move. Expand the window right to include more, shrink from left when the window becomes invalid. You're always looking at a "substring" or "subarray".
🧠 When To Recognize
longest/shortest substringcontiguous subarrayat most K distinctmaximum sum subarray of size Kanagram/permutation in stringwindow condition
📐 Step-by-Step Visual

Problem: Longest Substring Without Repeating Characters — "abcabcbb"

Step 1 — Expand right pointer, track chars in window
  "a b c a b c b b"
   L     R            window = {a,b,c}, len = 3
Step 2 — 'a' repeats → shrink from left until valid
  "a b c a b c b b"
     L     R          removed 'a', window = {b,c,a}, len = 3
Step 3 — Continue expanding and shrinking
  Track max length at each valid state.
  ✅ Answer: 3 ("abc")
  
  Template: for each right++, while(invalid) left++
  Answer = max(right - left + 1) over all valid windows
💻 Code
// Longest Substring Without Repeating (LC #3)
// Time: O(n)  Space: O(min(n, charset))
public int lengthOfLongestSubstring(String s) {
    Map<Character,Integer> map = new HashMap<>();
    int maxLen = 0, left = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (map.containsKey(c))
            left = Math.max(left, map.get(c) + 1); // shrink
        map.put(c, right);
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}

/* ─── SLIDING WINDOW TEMPLATE ───
   int left = 0;
   for (int right = 0; right < n; right++) {
       // add s[right] to window
       while (window is invalid) {
           // remove s[left] from window
           left++;
       }
       // update answer with current window [left..right]
   }
*/

func lengthOfLongestSubstring(s string) int {
    m := map[byte]int{}
    maxLen, left := 0, 0
    for right := 0; right < len(s); right++ {
        if idx, ok := m[s[right]]; ok && idx >= left {
            left = idx + 1
        }
        m[s[right]] = right
        if right-left+1 > maxLen { maxLen = right-left+1 }
    }
    return maxLen
}

def length_of_longest_substring(s):
    seen = {}
    max_len = left = 0
    for right, c in enumerate(s):
        if c in seen and seen[c] >= left:
            left = seen[c] + 1
        seen[c] = right
        max_len = max(max_len, right - left + 1)
    return max_len
⚠️ Edge Cases & Common Mistakes
  • Fixed vs variable window: Fixed = always size K. Variable = expand right, shrink left when constraint breaks.
  • Don't reset left to 0 when shrinking — only move it forward: left = max(left, ...).
  • For "find all anagrams" type: use a frequency counter, window is valid when all chars matched.
  • Empty string → return 0. Single char → return 1.
⏱️ Complexity
Time
O(n)
Each element enters and leaves window at most once.
Space
O(k)
k = size of character set or window constraint.

Prefix Sum
🌍 Real-World Analogy
A running total in your bank account. "How much did I spend between March and June?" → balance(June) - balance(February). Prefix sum pre-computes cumulative sums so any range sum is just one subtraction: sum(i..j) = prefix[j+1] - prefix[i].
🧠 When To Recognize
range sum querysubarray sum equals Kcontinuous subarraycumulative sumproduct of array except self
📐 Step-by-Step Visual

Problem: Subarray Sum Equals K — [1, 1, 1], k = 2

Key Insight — prefix sum + HashMap
  prefix = [0, 1, 2, 3]    prefix[0]=0 always!
  
  sum(i..j) = prefix[j+1] - prefix[i] = k
  So we need: prefix[j+1] - k = prefix[i]  →  lookup in HashMap!
  
  Scan prefix sums, for each p, check if (p - k) was seen before:
  p=0: p-k=-2 not in map. map={0:1}
  p=1: p-k=-1 not in map. map={0:1, 1:1}
  p=2: p-k=0 in map! count+=1. map={0:1, 1:1, 2:1}
  p=3: p-k=1 in map! count+=1.
  
  ✅ count = 2 → subarrays [1,1] and [1,1]
💻 Code
// Subarray Sum Equals K (LC #560) — Time: O(n)  Space: O(n)
public int subarraySum(int[] nums, int k) {
    Map<Integer,Integer> map = new HashMap<>();
    map.put(0, 1);                     // empty prefix
    int sum = 0, count = 0;
    for (int num : nums) {
        sum += num;
        count += map.getOrDefault(sum - k, 0); // need sum-k seen before
        map.merge(sum, 1, Integer::sum);
    }
    return count;
}

func subarraySum(nums []int, k int) int {
    m := map[int]int{0: 1}
    sum, count := 0, 0
    for _, num := range nums {
        sum += num
        count += m[sum-k]
        m[sum]++
    }
    return count
}

def subarray_sum(nums, k):
    prefix_count = {0: 1}
    total = count = 0
    for num in nums:
        total += num
        count += prefix_count.get(total - k, 0)
        prefix_count[total] = prefix_count.get(total, 0) + 1
    return count
⚠️ Edge Cases
  • Always initialize prefix map with {0: 1} — handles subarrays starting from index 0.
  • For range sum queries (immutable), build prefix array once, answer queries in O(1).
  • Prefix sum + HashMap = O(n) for "subarray sum = K". Without HashMap it's O(n²).
⏱️ Complexity
Time
O(n)
Single pass + O(1) HashMap lookups.
Space
O(n)
HashMap or prefix array.

Kadane's Algorithm
🌍 Real-World Analogy
Imagine walking and collecting coins (positive) and paying tolls (negative). At each point you decide: "Am I better off continuing my current journey, or starting fresh from here?" If the running total drops below the current element alone, reset — start a new subarray from here.
🧠 When To Recognize
maximum subarray summax contiguous subarrayoptimal subarraycircular subarray
📐 Step-by-Step Visual

Problem: Maximum Subarray — [-2, 1, -3, 4, -1, 2, 1, -5, 4]

At each element: max(element alone, running sum + element)
  nums:     -2   1  -3   4  -1   2   1  -5   4
  curr:     -2   1  -2  4   3   5   6   1   5
  maxSum:   -2   1   1   4   4   5  6   6   6
  
  curr = max(nums[i], curr + nums[i])
  At 4: max(4, -2+4=2) → 4 (start fresh!)
  At 2: max(2, 3+2=5) → 5 (continue!)
  
  ✅ Answer: 6 (subarray [4, -1, 2, 1])
💻 Code
// Maximum Subarray (LC #53) — O(n) time, O(1) space
public int maxSubArray(int[] nums) {
    int curr = nums[0], maxSum = nums[0];
    for (int i = 1; i < nums.length; i++) {
        curr = Math.max(nums[i], curr + nums[i]); // restart or continue?
        maxSum = Math.max(maxSum, curr);
    }
    return maxSum;
}

func maxSubArray(nums []int) int {
    curr, maxSum := nums[0], nums[0]
    for _, n := range nums[1:] {
        curr = max(n, curr+n)
        maxSum = max(maxSum, curr)
    }
    return maxSum
}

def max_sub_array(nums):
    curr = max_sum = nums[0]
    for n in nums[1:]:
        curr = max(n, curr + n)
        max_sum = max(max_sum, curr)
    return max_sum
⚠️ Edge Cases
  • All negative numbers → answer is the largest (least negative) single element.
  • Circular variant: maxCircular = max(normal Kadane, totalSum - minSubarray). If all negative, use normal Kadane only.
  • To find the actual subarray (not just the sum), track start/end indices when curr resets or updates maxSum.

Dutch National Flag
🌍 Real-World Analogy
Sorting a deck of cards into three piles (red, white, blue) in a single pass. Use three pointers: low marks the boundary of reds, mid scans through, high marks the boundary of blues. Current card is red? Swap to front. Blue? Swap to back. White? Move on.
🧠 When To Recognize
sort colors (0,1,2)three-way partitionpartition around pivotmove elements to sections
📐 Step-by-Step Visual
Sort Colors [2, 0, 2, 1, 1, 0]
  low=0, mid=0, high=5
  
  mid=0: nums[0]=2 → swap with high → [0,0,2,1,1,2] high=4
  mid=0: nums[0]=0 → swap with low  → [0,0,2,1,1,2] low=1,mid=1
  mid=1: nums[1]=0 → swap with low  → [0,0,2,1,1,2] low=2,mid=2
  mid=2: nums[2]=2 → swap with high → [0,0,1,1,2,2] high=3
  mid=2: nums[2]=1 → skip           → mid=3
  mid=3: nums[3]=1 → skip           → mid=4 > high → DONE
  
  ✅ [0, 0, 1, 1, 2, 2]  — single pass!
💻 Code
// Sort Colors (LC #75) — O(n) time, O(1) space, single pass
public void sortColors(int[] nums) {
    int lo = 0, mid = 0, hi = nums.length - 1;
    while (mid <= hi) {
        if (nums[mid] == 0) swap(nums, lo++, mid++);
        else if (nums[mid] == 2) swap(nums, mid, hi--);
        else mid++;  // nums[mid] == 1, leave in place
    }
}
void swap(int[] a, int i, int j) { int t=a[i]; a[i]=a[j]; a[j]=t; }

func sortColors(nums []int) {
    lo, mid, hi := 0, 0, len(nums)-1
    for mid <= hi {
        switch nums[mid] {
        case 0: nums[lo], nums[mid] = nums[mid], nums[lo]; lo++; mid++
        case 2: nums[mid], nums[hi] = nums[hi], nums[mid]; hi--
        default: mid++
        }
    }
}

def sort_colors(nums):
    lo, mid, hi = 0, 0, len(nums) - 1
    while mid <= hi:
        if nums[mid] == 0:
            nums[lo], nums[mid] = nums[mid], nums[lo]
            lo += 1; mid += 1
        elif nums[mid] == 2:
            nums[mid], nums[hi] = nums[hi], nums[mid]
            hi -= 1
        else:
            mid += 1
⚠️ Edge Cases
  • When swapping with high, do NOT increment mid — the swapped element needs checking.
  • When swapping with low, you CAN increment mid — low region is already processed.
  • All same values → no swaps, single pass.
