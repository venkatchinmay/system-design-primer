Fast & Slow Pointers (Floyd's)
🌍 Real-World Analogy
Two runners on a track — one runs twice as fast. If there's a loop, the fast runner eventually laps the slow one (they meet!). If no loop, fast runner reaches the end. Also: when fast is at the end, slow is at the MIDDLE — perfect for finding the midpoint!
🧠 When To Recognize
cycle detectionfind middlepalindrome linked listhappy numberkth from endFloyd's algorithm
📐 Step-by-Step Visual

Problem: Detect cycle in linked list

Step 1 — Two pointers: slow +1, fast +2
  1 → 2 → 3 → 4 → 5 → 3 (cycle back to 3)
  S                          slow = 1
  F                          fast = 1
Step 2 — Move until they meet
  Step 1: slow=2, fast=3
  Step 2: slow=3, fast=5
  Step 3: slow=4, fast=4   ✅ They meet! Cycle exists!
  
  For finding middle: when fast reaches end, slow is at middle
  1 → 2 → 3 → 4 → 5
           S         F(end)   → slow = 3 = middle!
💻 Code
// Cycle Detection (LC #141) — O(n) time, O(1) space
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;   // they met → cycle!
    }
    return false;                         // fast reached end → no cycle
}

// Find Middle (LC #876)
public ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next; fast = fast.next.next;
    }
    return slow;  // slow is at middle when fast reaches end
}

    slow, fast := head, head
    for fast != nil && fast.Next != nil {

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next; fast = fast.next.next
        if slow == fast: return True
    return False

def middle_node(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next; fast = fast.next.next
    return slow
⚠️ Edge Cases
  • Empty list or single node → no cycle (fast is null immediately).
  • For finding cycle start: after slow==fast, reset one to head and move both +1 — they meet at cycle start.
  • Even vs odd length: for middle, decide if you want left-middle or right-middle by adjusting the while condition.

In-Place Linked List Reversal
🌍 Real-World Analogy
A conga line doing an about-face. Each person turns around and grabs the shoulder of the person who was BEHIND them. You process one person at a time: save next, flip the arrow, move forward. Three pointers: prev, curr, next.
🧠 When To Recognize
reverse linked listreverse between positionsreverse in groups of Kswap nodes in pairs
📐 Step-by-Step Visual
Reverse 1 → 2 → 3 → null
  prev=null, curr=1
  
  Step 1: next=2, 1→null, prev=1, curr=2
  null ← 1    2 → 3 → null
  
  Step 2: next=3, 2→1, prev=2, curr=3
  null ← 1 ← 2    3 → null
  
  Step 3: next=null, 3→2, prev=3, curr=null → DONE!
  null ← 1 ← 2 ← 3  →  3 → 2 → 1 → null
💻 Code
// Reverse Linked List (LC #206) — O(n) time, O(1) space
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;   // save next
        curr.next = prev;            // flip arrow
        prev = curr;                 // advance prev
        curr = next;                 // advance curr
    }
    return prev;                     // new head
}

// Reverse Between m and n (LC #92)
public ListNode reverseBetween(ListNode head, int m, int n) {
    ListNode dummy = new ListNode(0, head);
    ListNode pre = dummy;
    for (int i = 1; i < m; i++) pre = pre.next;
    ListNode curr = pre.next;
    for (int i = 0; i < n - m; i++) {
        ListNode next = curr.next;
        curr.next = next.next;
        next.next = pre.next;
        pre.next = next;
    }
    return dummy.next;
}

func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    curr := head
    for curr != nil {
        next := curr.Next
        curr.Next = prev
        prev = curr; curr = next
    }
    return prev
}

def reverse_list(head):
    prev, curr = None, head
    while curr:
        nxt = curr.next
        curr.next = prev
        prev = curr
        curr = nxt
    return prev
⚠️ Edge Cases
  • Use a dummy node when the head might change (reversal starting from position 1).
  • Reverse in K-group: count K nodes exist first, then reverse; if fewer than K, leave as-is.
  • Draw it out on paper! Reversal bugs are almost always pointer-order mistakes.
