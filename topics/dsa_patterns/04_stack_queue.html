Monotonic Stack
🌍 Real-World Analogy
Standing in a crowd looking for the next taller person. As you scan right, you maintain a stack of people in decreasing height. When a taller person appears, everyone shorter gets popped — they've found their "next greater element". The stack always stays monotonic!

Problem: Daily Temperatures — [73,74,75,71,69,72,76,73] → days until warmer

Maintain a stack of indices with decreasing temps
  i=0: push 0. Stack: [0(73)]
  i=1: 74>73 → pop 0, ans[0]=1-0=1. Push 1. Stack: [1(74)]
  i=2: 75>74 → pop 1, ans[1]=2-1=1. Push 2. Stack: [2(75)]
  i=3: 71<75 → push. Stack: [2(75), 3(71)]
  i=4: 69<71 → push. Stack: [2(75), 3(71), 4(69)]
  i=5: 72>69 → pop 4, ans[4]=5-4=1. 72>71 → pop 3, ans[3]=5-3=2. Push 5.
  i=6: 76>72 → pop 5 ans[5]=1. 76>75 → pop 2, ans[2]=6-2=4. Push 6.
  i=7: 73<76 → push. Remaining in stack → ans=0 (no warmer day)
  
  ✅ Answer: [1, 1, 4, 2, 1, 1, 0, 0]
💻 Code
// Daily Temperatures (LC #739) — O(n) time & space
public int[] dailyTemperatures(int[] temps) {
    int n = temps.length;
    int[] ans = new int[n];
    Deque<Integer> stack = new ArrayDeque<>(); // indices
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && temps[i] > temps[stack.peek()]) {
            int idx = stack.pop();
            ans[idx] = i - idx;
        }
        stack.push(i);
    }
    return ans;
}

func dailyTemperatures(temps []int) []int {
    n := len(temps); ans := make([]int, n)
    stack := []int{}
    for i := 0; i < n; i++ {
        for len(stack) > 0 && temps[i] > temps[stack[len(stack)-1]] {
            idx := stack[len(stack)-1]; stack = stack[:len(stack)-1]
            ans[idx] = i - idx
        }
        stack = append(stack, i)
    }
    return ans
}

def daily_temperatures(temps):
    n = len(temps); ans = [0] * n
    stack = []  # indices
    for i in range(n):
        while stack and temps[i] > temps[stack[-1]]:
            idx = stack.pop()
            ans[idx] = i - idx
        stack.append(i)
    return ans
⚠️ Edge Cases
  • Store indices on the stack, not values — you need indices to compute distances and access values.
  • Decreasing stack → finds next GREATER. Increasing stack → finds next SMALLER.
  • For "previous greater/smaller": iterate from left, answer when popping. For "next": iterate and answer based on what's on stack.

Top-K Elements / Heap
🌍 Real-World Analogy
A talent show keeping only the top 3 performers. As each act performs, compare with the lowest-scoring finalist. Better? Replace them. The min-heap always holds the best K, and the worst of the K is quickly accessible at the top.

💻 Code
// Top K Frequent Elements (LC #347)
// Time: O(n log k)  Space: O(n + k)
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer,Integer> freq = new HashMap<>();
    for (int n : nums) freq.merge(n, 1, Integer::sum);
    
    // Min-heap of size k — keeps the top k
    PriorityQueue<Integer> pq = new PriorityQueue<>(
        (a,b) -> freq.get(a) - freq.get(b));
    for (int key : freq.keySet()) {
        pq.offer(key);
        if (pq.size() > k) pq.poll();  // remove least frequent
    }
    return pq.stream().mapToInt(i->i).toArray();
}

// Kth Largest Element (LC #215) — min-heap of size k
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    for (int n : nums) {
        pq.offer(n);
        if (pq.size() > k) pq.poll();
    }
    return pq.peek();
}

// Using container/heap
func findKthLargest(nums []int, k int) int {
    h := &IntHeap{}
    for _, n := range nums {
        heap.Push(h, n)
        if h.Len() > k { heap.Pop(h) }
    }
    return (*h)[0]
}

import heapq
def top_k_frequent(nums, k):
    freq = Counter(nums)
    return heapq.nlargest(k, freq.keys(), key=freq.get)

def find_kth_largest(nums, k):
    heap = []
    for n in nums:
        heapq.heappush(heap, n)
        if len(heap) > k: heapq.heappop(heap)
    return heap[0]
⚠️ Edge Cases
  • Top K largest → use min-heap of size K (not max-heap!). The smallest of the top K is at the root.
  • For merge K sorted lists: put first element of each list in heap, pop min, push its successor.
  • Python's heapq is a min-heap. For max-heap, negate values.

Parentheses / Stack Patterns
🌍 Real-World Analogy
Nesting dolls — each opening bracket is like opening a new doll. When you close a doll, it must match the most recently opened one (LIFO!). If you try to close a doll that doesn't match, or have unclosed dolls at the end, it's invalid.
💻 Code
// Valid Parentheses (LC #20) — O(n) time & space
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') stack.push(')');
        else if (c == '{') stack.push('}');
        else if (c == '[') stack.push(']');
        else if (stack.isEmpty() || stack.pop() != c) return false;
    }
    return stack.isEmpty();
}

def is_valid(s):
    stack, pairs = [], {'(':')', '{':'}', '[':']'}
    for c in s:
        if c in pairs: stack.append(pairs[c])
        elif not stack or stack.pop() != c: return False
    return not stack
